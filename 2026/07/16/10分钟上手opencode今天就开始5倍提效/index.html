一、你只差这 10 分钟

如果你已经下载了 opencode，但面对命令行界面不知道该从哪开始 —— 你不是一个人。

这个问题很普遍：AI 编程工具的宣传片都展示各种炫酷操作，但新手开机后的第一公里往往没人管。“东西装好了，然后呢？”

这篇文章的目标很简单：花 10 分钟完成从零到跑通真东西的全过程。

10 分钟之后，你将拥有：

  • 一个跑通的 opencode 环境

  • 一套可以复用的 “想法 → 代码” 工作流

这是一笔 ROI 极高的时间投资。开始吧。

2.2 配置模型

opencode 的核心哲学是 模型中立——你可以接任何模型。但新手最需要的是”开箱即用”。

推荐路径：使用内置免费模型

opencode 自带免费模型（DeepSeek V4 Flash Free），无需任何 API Key，装完即用。启动后在界面中选择 Zen 提供商的 DeepSeek V4 Flash Free 即可。

如果之后需要更强的能力，升级路径也很平滑：

  • OpenCode Go：$5/首月，之后 $10/月，接入 DeepSeek V4 Pro、Qwen3.7 Max 等开源强模型
  • BYOK：绑定你自己的 Claude / GPT / Gemini API Key
  • OpenCode Zen：$20 预付费，按量计费，零加成

Demo 4：全功能番茄钟网页

场景：想要一个漂亮的番茄钟，没有广告，没有注册，开箱即用。

纯前端，零依赖，双击即可打开。功能齐全：

  • 专注/休息模式切换
  • 进度条
  • 自定义时长
  • 本地存储统计

用 opencode 生成这个番茄钟，前后对话了三四轮：第一轮生成基础版，第二轮加进度条和暂停功能，第三轮美化样式，第四轮加本地统计。整个过程大概 5 分钟。

对比传统的做法：打开 CodePen 或 VS Code → 写 HTML 结构 → 写 CSS 样式（调半天） → 写 JS 逻辑（处理各种边缘情况） → 调试。30 分钟起步，上不封顶。
