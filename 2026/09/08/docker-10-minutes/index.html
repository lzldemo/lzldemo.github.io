Docker 10-Minute Quick Start Guide

A hands-on tutorial based on Ubuntu. Complete all 5 tasks in 10 minutes with copy-paste commands and explanations.

What is Docker?

Docker is a containerization platform that packages applications and their dependencies into isolated containers. It ensures consistent operation across any environment.

Core Concepts:

  • Image: A read-only template (like an “installer package”)
  • Container: A running instance of an image
  • Registry: Image repository (e.g., Docker Hub)
  • Volume: Persistent storage (data survives container deletion)
  • Network: Virtual switch for container-to-container communication

Command Quick Reference

Action Command
List running containers docker ps
List all containers docker ps -a
List images docker images
Enter a container docker exec -it CONTAINER bash
View container logs docker logs CONTAINER
Build an image docker build -t IMAGE_NAME .
Run a container docker run -d --name CONTAINER_NAME IMAGE
Stop a container docker stop CONTAINER
Remove a container docker rm CONTAINER
Remove an image docker rmi IMAGE
List networks docker network ls
List volumes docker volume ls

Troubleshooting

Issue Solution
ping: command not found Minimal images lack ping. Use getent hosts CONTAINER_NAME or Python socket test instead.
docker logs shows nothing Add flush=True in Python prints, or use python -u to launch.
docker exec ... -p fails The command is missing. Correct syntax: docker exec mysql-demo mysql -p.
Port already in use Change port mapping: -p 8081:80 instead of -p 8080:80.
Slow image pulls Configure a registry mirror (e.g., Aliyun, USTC).
Permission denied on volume For testing only: sudo chmod -R 777 ~/mysql_data.
